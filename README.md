# Sistema de Controle de Estoque

Sistema de controle de estoque via terminal, desenvolvido em Python.

## 📋 Funcionalidades

- Cadastro de produtos (nome, quantidade e preço)
- Listagem de todos os produtos em estoque
- Atualização de quantidade (entrada e saída de itens)
- Edição de nome e preço de produtos
- Remoção de produtos
- Busca de produto por ID

## 🚀 Como executar

1. Certifique-se de ter o Python instalado (versão 3.6 ou superior)
2. Clone este repositório:
```bash
git clone https://github.com/richardbarsotti23-lab/sistema-estoque-python.git
```
3. Execute o programa:
```bash
python estoque.py
```

## 🛠️ Tecnologias utilizadas

- Python 3
- Estrutura de dados (dicionários)
